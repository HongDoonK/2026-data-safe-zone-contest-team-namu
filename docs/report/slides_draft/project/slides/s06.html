데이터는 세 갈래다. 안심구역의 미개방 상호제공 데이터(대구로 결제·가맹점·배달·고객, KCB 소득), 공개 데이터(인구, 대응표, 경계), 그리고 현장 확인(앱 점검, 구청·시청). 가맹점 법정동과 인구·소득의 행정동이 어긋나서, 둘을 이어 결합 단위 71곳을 만들어 연결 키로 쓴다. KCB와 배달·고객 집계는 4차 반출 결과에 따라 확정한다.
