Ⅰ. 문제 정의

진단 → 이유 판정 → 처방, 규칙은 결과보다 먼저

① 진단

시간: 레짐·시각 분포
공간: 방학 이용 비중, 아동 1천 명당
→ 1순위 17곳

② 이유 판정

7가지 × 해당·아님·판단 불가
소득, 주문 흐름, 가게 상태, 앱 점검
→ 확정·추정·제외·미확정

③ 처방·시나리오

유형별 조치와 주체
가게 늘리기 대 장벽 낮추기
→ 같은 단위로 효과 비교

원칙 1

판정 규칙은 반출물을 보기 전에 고정한다 (2026-10-13)

원칙 2

진단 숫자와 시나리오(가정) 숫자를 섞지 않는다

5

분석은 세 단계다. 진단에서 덜 쓰는 동네를 고르고, 이유 7가지를 데이터로 판정하고, 판정 유형별로 처방과 효과를 낸다. 규칙은 결과를 보기 전에 고정했고, 시나리오 숫자는 가정 아래의 계산이라 진단 결론과 섞지 않는다.
