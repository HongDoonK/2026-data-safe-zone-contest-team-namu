def judge_one(x, hit, ok, bad):
    if pd.isna(x):
        return "?자료"
    if bad == "low":
        return "●" if x <= hit else ("○" if x >= ok else "?경계")

def merge2(a, b, conflict="?억제"):
    return a if a == b else conflict  # 두 판정이 같을 때만 확정 (요약)

① 문턱

대구 분포의 하위 25%면 해당, 중앙값 반대편이면 아님

② 가린 칸

0과 (가림 문턱 − 1)로 채워 두 번 판정

③ 확정

두 판정이 같을 때만. 다르면 ‘판단 불가’

④ 묶기

착시 제외 → 처방 확정 → 잔여 추정 → 미확정

증빙 4: 판정 코드의 핵심. 반출 자료에는 작은 칸이 가려져 있다. 가린 칸을 가장 불리한 값과 가장 유리한 값으로 채워 두 번 판정하고, 두 판정이 같을 때만 확정한다. 판정이 끝나면 착시를 먼저 빼고, 처방 확정, 잔여 추정, 미확정 순서로 묶는다.
