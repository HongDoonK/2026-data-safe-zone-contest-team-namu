## 1. 문제 정의

결식 우려 아동에게 지급되는 급식카드는 **"가맹점이 있는 곳에서, 영업하는 시간에만"** 작동한다.

지원 단가를 올려도 쓸 수 있는 장소와 시간이 없으면 지원은 도달하지 않는다. 그런데 실제 사용 실태는 행정 통계로 관측된 적이 없다.

> 논의의 축을 **"지원 단가"에서 "지원 접근성"으로** 옮기는 것이 이 연구의 목표다.

### 왜 미개방데이터여야 하는가

공개되는 것은 지자체별 지원 아동 수와 가맹점 총수뿐이다. **언제·어디서 실제로 사용되었는지, 그리고 그 주문이 성공했는지**는 집계 과정에서 전부 소멸한다.

- `INS_001.PAY_GBN` 값 목록에 **"아동급식카드"가 명시**되어 있다 → 개별 거래 식별 가능
- `INS_004.CHILD_ABLE_YN` (아동급식 가능 가맹점) 이 22,087개 가맹점 전수에 존재
- 배차 형평성 분석은 플랫폼 내부 타임스탬프 없이는 착수조차 불가능

### 선례 확인

2025년 수상작 28건 중 아동복지·급식지원 주제가 없다. 대구로 플랫폼 데이터를 활용한 사례도 확인되지 않는다.

## 3. 원본 정의서 재확인에서 드러난 제약

정의서 전 컬럼을 다시 확인한 결과, 초기 기획에서 **5개 지점을 수정**했다. 설계의 상당 부분이 여기서 결정된다.

| 발견 | 대응 |
| --- | --- |
| **가맹점 테이블에 업종 컬럼이 없다** | 업종 축을 신한카드 업종중분류(행정동 단위) + 가맹점의 시간대 주문 프로파일로 대체 |
| **배달 목적지가 어디에도 없다** | 관측되는 동은 가맹점 소재 동뿐. 인접 행정동을 포함한 **공간 시차 커버리지**로 지표 재정의 |
| **결제·주문은 시 단위, 배달만 분 단위** | "주문→배차 지연"은 ±60분 오차 불가피 → 1차 결과변수를 **배차→완료 소요시간**(분 단위)으로 교체 |
| **KCB 연령 하한이 20세** | 아동 인구는 공개데이터로 조달. KCB는 성인 소득분포로만 사용 |
| **지역 코드 체계가 셋 다 다름** | 행정동명(대구로) / 행정동코드(KCB) / 법정동코드(신한카드) → 브리지 테이블 별도 구축 |

## 4. 핵심 가설

| | 가설 | 검증 방법 |
| --- | --- | --- |
| **H1** | 급식카드 결제는 특정 시간대에 집중되며 심야·주말에 급감한다 | χ² 동질성 검정 + **가맹점 내 대조**(같은 가게에서 급식 vs 일반 비교) |
| **H1-b** | 급식카드 결제의 행정동 분포가 일반 결제와 다르다 | 위치몫(LQ) + Moran's I 공간 군집 검정 |
| **H2** | 급식 가맹점 밀도가 아동 인구·소득과 정합하지 않는다 | 음이항 회귀 + 잔차 공간자기상관 + **LISA 군집 식별** |
| **H3** | 급식카드 주문은 배달 결과에서 불리하며, 그 격차는 배달팁을 통해 매개된다 | 가맹점 고정효과 회귀 + **매개분해** + 성향점수 매칭 |
| **H4** | 급식 가맹점의 폐업 위험이 유사 조건 일반 가맹점과 다르다 | 이산시간 생존분석 + Kaplan-Meier |
| **H5** | 결제금액이 **지원 단가 상한에 집군**하며, 단가 인상 시 집군점이 이동한다 | 초과질량 추정 + 단가 개정 시점 이벤트 스터디 |

> **H5는 이 설계에서 신설한 가설이다.** 결합이 필요 없고, 데이터가 적어도 성립하며, "예산 증액이냐 접근성이냐"라는 원 문제의식을 정면으로 검정하는 유일한 가설이다.

## 5. 분석 방법

### 5.1 전체 파이프라인

```text
Raw Data (INS_001~006)
   ↓
게이트 검증 ★  PAY_GBN 값 분포 / 급식카드 건수 · 월별 추이
   ↓
결합           결제-주문-배달-가맹점 (규칙 3종 비교)
   ↓
브리지 구축     행정동명 → 행정동코드 → 법정동코드
   ↓
지수 설계       DCAI = 아동 1,000명당 유효 급식 가맹점 수
   ↓
가설 검정       H1·H1-b·H2·H4·H5
   ↓
모형           H3: 가맹점 고정효과 + 매개분석 + 성향점수 매칭
   ↓
산출           사각지대 지도 / 커버리지 히트맵 / 가맹점 모집 우선순위
```

### 5.2 결합 규칙 — 주문번호가 없다는 문제

결제·주문·배달을 잇는 공통키는 `SHOP_ID` + `CUST_ID` + 시각뿐이다. 주문번호가 없다.

**규칙 3종을 병렬 실행하고 결과가 모두에서 재현되는지 보고한다.**

| 규칙 | 방법 | 성격 |
| --- | --- | --- |
| **R1** | 정확 키 1:1, 모호하면 전량 폐기 | 오매칭 0. 기준선 |
| **R2** | ±1시간 창 + 최근접 1:1 배정 | 주력 후보 |
| **R3** | 결합 포기, (가맹점, 날짜, 시) 셀 단위 집계 | 매칭 오차가 원리적으로 없는 대안 |

**핵심 진단 — 순열 위약검정**

블록 내에서 `CUST_ID`를 무작위로 섞은 뒤 같은 규칙을 재실행한다. 여기서 나오는 매칭률이 "키가 아무것도 식별하지 못할 때의 매칭률"이다.

- 실제 ≫ 위약 → 키가 개별 거래를 실제로 식별한다
- 실제 ≈ 위약 → R3(셀 집계)로 전환

### 5.3 리스크 격리 — 결합 실패가 주제를 무너뜨리지 않는다

| 가설 | 필요한 결합 | 결합 실패 시 |
| --- | --- | --- |
| H1 · H1-b · H2 · H4 · H5 | **가맹점코드 단일키 (무손실)** | **영향 없음** |
| H3 | 결제⋈주문⋈배달 3자 결합 | R3로 재정식화 |

6개 가설 중 5개는 단일키 결합만으로 성립한다.

### 5.4 DCAI — 접근성 지수 설계

**영업시간을 직접 관측할 수 없다.** 가맹점 테이블에 영업시간 컬럼이 없다. 유일한 대리변수는 그 가맹점에서 실제로 주문이 발생한 시간대 분포다.

```text
π(가맹점, 요일-시간, 월)
  = 그 시간에 주문이 1건 이상 발생한 날의 수 / 해당 요일의 총 일수
```

**이 대리값의 약점**: "닫혀 있음"과 "열려 있지만 주문이 없음"이 구분되지 않는다.

대응 4가지:

- [ ] 월 주문건수 임계치 미만 가맹점 제외 (8/12/20건 민감도 분석)
- [ ] 규모에 영향받지 않는 상대 프로파일 병행 산출
- [ ] **신한카드 시간대별 소비 분포와 상관 확인** → 두 독립 출처가 같은 시간 구조를 보이면 타당성 보강
- [ ] 지수명을 "영업시간"이 아니라 "관측된 주문 수용 가능성"으로 명명

**지수 정의**

```text
DCAI(동, 시간, 월) = 유효 급식 가맹점 수 / (아동 인구 / 1000)
```

배달은 동 경계를 넘으므로, 인접 행정동의 공급을 가중치 λ로 포함한다. λ는 데이터로 추정할 수 없으므로 **{0, 0.25, 0.5} 세 값으로 전 결과를 재현**한다.

**사각지대 판정 규칙** (사후 조정 없이 사전 등록)

동시에 만족하는 행정동-시간 셀:

1. DCAI가 대구 전체 하위 25%
2. 아동 인구가 중위 이상
3. 해당 시간대 외식 소비가 중위 이상 (수요는 있음)

### 5.5 H3 매개분석 구조

**결과변수**

| 우선 | 변수 | 정밀도 |
| --- | --- | --- |
| 1차 | 배차→완료 소요시간 | **분** (두 값 모두 분 단위) |
| 1차 | 배달 취소 여부 | 이진 |
| 2차 | 주문→배차 시차 | 시 (±60분 오차) |

**모형 구조**

```text
(1) 총효과    Y = τ·D           + 가맹점FE + 요일시간FE + 연월FE + 통제
(2) 매개경로  M = a·D           + (동일)
(3) 직접효과  Y = τ'·D + b·M    + (동일)
```

- 매개변수: **배달팁**, **주문금액**
- **가맹점 고정효과 필수** — 급식 가맹점의 업종·입지가 애초에 다르다. 업종 컬럼이 없으므로 이것이 유일한 방어
- 신뢰구간: 가맹점 단위 블록 부트스트랩 1,000회

**어느 방향이 나와도 결론이 있다**

| 결과 | 해석 | 정책 함의 |
| --- | --- | --- |
| 직접효과 ≈ 0 | 가격 메커니즘이 격차를 만든다 | 급식 주문 배달팁 보조 |
| 직접효과 ≠ 0 | 가격으로 설명되지 않는 잔여 격차 | 우선 배차 규칙 |

**선택 편의 대응 — 성향점수 매칭**

업종을 관측할 수 없으므로, 매칭 공변량으로 업종을 대리한다.

| 범주 | 변수 |
| --- | --- |
| 규모 | 월평균 주문건수, 결제금액 중위값, 고유 고객 수 |
| 가격대 | 주문금액 분위, 배달팁 중위값 |
| **업종 대리** | **시간대 주문 프로파일의 주성분 1~3** |
| **업종 대리** | 포장 주문 비율, 평균 조리대기시간 |
| 운영 | 평균 별점, 별점 표준편차, 리뷰 수 |
| 고객구성 | 연령대 구성비, 성비 |
| 입지 | 행정동 총 가맹점 수, 아동 인구, 소득, 업종 구성비 |

> **핵심 아이디어**: 업종 컬럼이 없어도 "점심에만 팔리는 가게"와 "야식만 팔리는 가게"는 시간대 프로파일이 전혀 다르다. 프로파일 주성분으로 매칭하면 관측되지 않는 업종을 상당 부분 균형시킬 수 있다.

정확 일치는 구·군, 캘리퍼 0.2 SD, 균형 진단은 표준화 평균차 0.1 미만.

| --- | --- | --- |
| **원안** | 10만 건 이상 + 가맹점 500곳 이상 + 24개월 이상 | H1~H5 전부. 개별 결제 기반 히트맵 |
| **축소** | 2만~10만 건 | H2·H4·H5 유지. H3은 고정효과 포기, 매개분해는 기술통계로 강등 |
| **1차 fallback** | 2천~2만 건 | 분석 단위를 **가맹점×월로 격상**. 가맹점 전수 기반 접근성·생존 분석이 주력. H5 유지 |
| **2차 fallback** | 2천 건 미만 | 주제를 **배차 실패 구조("배달 사막")** 로 전환. 결합 규칙·지수·시각화·브리지는 전부 재사용 |

**건수만 보지 않는다.** 결제가 소수 가맹점에 몰려 있으면 공간 분석이 성립하지 않고 재식별 억제 기준에도 걸린다. 그래서 **가맹점 수를 동시에 요구**한다.

### 구조 변화 탐지

배달앱 급식카드 결제는 특정 시점에 도입됐을 가능성이 높다. 어디부터가 "정상 운영 구간"인지 정해야 분석 기간이 확정된다.

- 주 계열은 **건수가 아니라 비중** (플랫폼 자체 성장 효과 제거)
- 변화점 탐지 + 공개 공고의 정책 시점과 대조
- **확산 vs 수준 이동 구분**: 가맹점 수·행정동 수가 함께 뛰면 공급 확대, 비중만 뛰면 기존 사용자의 빈도 증가 → 정책 해석이 완전히 달라진다

## 7. 산출물

### 핵심 3종

**① 급식카드 사각지대 지도**

행정동 이변량 코로플레스 (필요도 × 공급). 패널 3장 — 평일 방과후 / 평일 저녁 / 주말 낮. 시간대별로 사각지대가 이동하는 것을 보인다.

**② 커버리지 히트맵**

행정동(결핍순) × 요일-시간. 값은 아동 1,000명당 유효 급식 가맹점 수.

> 이 그림 한 장이 "언제·어디서 멈추는가"라는 제목에 직접 답한다. 발표 대표 슬라이드.

**③ 가맹점 모집 우선순위 표**

| 컬럼 | 출처 |
| --- | --- |
| 행정동 / 시간대 / 아동 수 / 저소득 비율 | 대구로 + 공개 + KCB |
| 현재 급식 가맹점 수 / DCAI / 결핍도 순위 | 산출 |
| **모집 가능 풀** (그 동·그 업종 전체 가맹점 수) | **신한카드** |
| **목표 달성 필요 추가 수** | 산출 |
| 실행 난이도 / 수요 존재 여부 | 산출 |

> "필요 추가 수"와 "모집 가능 풀"이 나란히 있는 것이 핵심이다. 행정 담당자가 **"이 동에서 몇 곳을, 어느 업종에서 모집하면 되는가"** 를 바로 읽을 수 있다.

## 9. 연구의 범위 — 무엇을 주장하지 않는가

### 결제자가 아동이라는 보장이 없다

보호자 대리 결제가 가능하고, 계정 연령대는 명의자 기준이다.

> 본 연구가 관측하는 것은 아동의 식생활이 아니라, **급식 지원 수단이 사용되는 시공간과 그 제약**이다. 개인 단위의 아동 특성·식습관·영양 상태에 대해서는 어떠한 주장도 하지 않는다.

### 측정하는 것은 접근성의 하한이다

오프라인 급식 가맹점 직접 결제, 타 배달 플랫폼, 편의점·급식소는 관측되지 않는다.

> 특정 동의 지표가 낮다는 것이 곧 그 동 아동의 급식 접근성이 낮음을 뜻하지 않는다. 다만 **이동이 어려운 시간대·기상 조건·보호자 부재 상황에서 배달 경로의 중요성이 커진다**는 점에서, 배달 경로의 공백은 그 자체로 정책적 의미를 갖는다.

### 인과 주장의 한계

업종 정보가 데이터에 없어 업종 차이를 직접 통제하지 못했다. 매개분해는 **인과적 매개효과가 아니라 관측 가능한 가격 경로를 통한 기술적 분해**로 해석해야 한다.

### 재식별 방지 — 최소 집계 기준

| 규칙 | 임계 |
| --- | --- |
| 셀 관측 건수 | 5건 이상 |
| 고유 가맹점 수 | 3곳 이상 |
| 고유 고객 수 | 5명 이상 |
| 공간 최소 단위 | 행정동 (개별 가맹점 위치 공표 금지) |
| 교차 집계 | 최대 3축 (급식×성별×연령×동 조합 금지) |
| 공표 시간 단위 | 3시간 구간 |

억제 규칙은 파이프라인의 공표 직전 함수 하나로 구현한다. **사람이 기억해서 지키는 방식은 쓰지 않는다.** 억제된 셀은 지도에 회색 "집계 기준 미달"로 표시하고, 억제 규모를 부록에 보고한다.

### 낙인 효과 방지

"취약 동네" "결핍 지역"이 아니라 **"가맹점 확충 우선 지역"** 으로 표현한다. 같은 정보, 다른 프레임.
