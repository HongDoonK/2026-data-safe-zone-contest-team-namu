### M2. 비교군 — H1 검정 (90분) — 반출 2순위

**정의**: `G` = 급식 / 일반(급식이 아닌 모든 승인 결제). 레짐 `R` = 방학(1·2·8월) / 전환(7·12월) / 학기(나머지) — 결과 문서 §3.1과 동일. 분석 기간은 급식 관측 기간 **2023-06~2025-06**으로 맞춘다.

| 표 | 행 × 열 | 값 | 용도 |
|---|---|---|---|
| **T2-a** | 연월 × G | 건수·가게·계정 | **s_t** = 급식/전체. 플랫폼 성장 효과 분리 |
| **T2-b** | G × R × 요일(7) × 시(24) | 건수 | H1 프로파일 비교. **대구 전체이므로 1시간 단위 허용**(설계서 R-8) |
| **T2-c** | **가맹점 내 대조**: 급식·일반 결제가 모두 있는 가게만. G × R × 요일구분(평일/주말) × 3시간대(8구간) | 건수·가게·계정 | 가게 구성 효과를 제거한 H1 |
| **T2-d** | T2-c 기준 G별 시간대 비중 차이와 **가게 단위 블록 부트스트랩 95% CI** (500회, seed 고정) | 비중 차 · CI | 반복 계정·가게 군집을 반영한 불확실성(레드팀 R17) |

**안에서 계산하고 밖으로 가져올 요약 통계**: 레짐별 Cramér's V(급식 vs 일반, 3시간대), 가맹점 내 대조의 최대 비중 차이 시간대와 CI. **p값은 표본이 커서 거의 무의미하므로 효과크기와 CI를 주 결과로 한다.**

**해석 틀 — 어느 결과든 서사가 있다** (결과 예측 아님)

| 결과 | 기획서 서술 |
|---|---|
| 가맹점 내 대조에서도 시간 분포가 다름 | 급식카드는 **고유한 시간 수요**를 갖는다 → 그 시간의 가맹점 활동이 공급 측 병목 후보 |
| 원자료에선 다르지만 가맹점 내 대조에선 같음 | 차이는 **어떤 가게가 급식을 받느냐**에서 온다 → 가맹점 구성(H2)이 핵심 |
| 둘 다 같음 | 급식카드는 **일반 배달 패턴을 따른다** → "시간" 축보다 "공간·계절" 축이 주제의 중심 |

### M3. 가맹점 테이블 + 첫 결합 (60분) — 반출 4순위 해소

```sql
-- T3-a: INS_004 프로파일
SELECT COUNT(*) rows, COUNT(DISTINCT SHOP_ID) shops FROM shop;         -- 유일성
SELECT CHILD_ABLE_YN, STORE_STATUS, SERVICE_CLOSED, COUNT(*) FROM shop GROUP BY 1,2,3;
SELECT GUNGU_NM, COUNT(*), COUNT(DISTINCT DONG_NM) FROM shop GROUP BY 1;  -- 군위 포함 여부
SELECT LENGTH(DONG_NM) len, COUNT(DISTINCT DONG_NM) FROM shop GROUP BY 1; -- 법정동 판정

-- T3-b: 급식결제 발생 가게 × 등록 상태 (가게 단위 2×2 + 참조 실패)
WITH meal_shop AS (SELECT DISTINCT SHOP_ID FROM pay WHERE <급식필터>),
     any_shop  AS (SELECT DISTINCT SHOP_ID FROM pay)
SELECT s.CHILD_ABLE_YN,
       (m.SHOP_ID IS NOT NULL) has_meal_pay, COUNT(*) shops
FROM any_shop a LEFT JOIN shop s USING(SHOP_ID) LEFT JOIN meal_shop m USING(SHOP_ID)
GROUP BY 1,2;
```

**산출 지표와 판정**

| 지표 | 정의 | 읽는 법 |
|---|---|---|
| 참조율 | 결제의 `SHOP_ID` 중 `INS_004`에 있는 비율 | 낮으면 폐업·이탈 가게 행이 스냅샷에서 빠졌다는 신호(레드팀 R02) |
| **정합률 P(Y \| 급식결제 있음)** | 급식결제 발생 가게 중 `Y` 비율 | 높으면 `CHILD_ABLE_YN`이 "급식 수용 등록"으로 작동. **낮으면 현재 스냅샷이 과거와 다르거나 의미가 다름** → Y 기반 공급 지표 보류 |
| **활성률 P(급식결제 있음 \| Y)** | Y 가게 중 급식결제가 한 번이라도 있는 비율 | "등록됐지만 급식 주문이 관측되지 않은 가게"의 규모. **사용 불가로 해석하지 않는다**(레드팀 R01) |
| 급식결제 가게의 건수 분포 | 가게별 전 기간 급식 건수의 분위(p50/p90/p99)·상위 10% 점유율 | 소수 가게 집중 여부 → H3 가맹점 FE 가능성 |

추가로 **센터에 문의**: `INS_004` 스냅샷 기준일, `CHILD_ABLE_YN` 변경 이력 보관 여부. `[ASK]`

### M4. 공간 공표 가능성과 첫 지역 집계 (60분)

|---|---|---|---|
| L1 | 동 × 레짐 × 3시간대 | | |
| L2 | 동 × 레짐 | | |
| L3 | 동 × 전 기간 | | |
| L4 | 군구 × 레짐 × 3시간대 | | |
| L5 | 군구 × 레짐 | | |

**사전 고정 규칙**: 통과 셀이 **건수 기준 90% 이상**인 가장 세밀한 단계를 주 지도 단위로 삼는다. 이 표(G1표) 자체를 반출한다 — 수치 없이 비율만 담기므로 위험이 낮다. 90%는 결과를 보기 전 정한 운영 기준이며, 70%·80%에서의 결정도 함께 기록한다.
