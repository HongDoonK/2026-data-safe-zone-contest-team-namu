# 2차 반출 신청 — 파일 설명 (2026-09-18)

> 반출 신청서 작성용. 코드는 현장 손타이핑 셀 1~12([T2_visit2_field_report.md](T2_visit2_field_report.md)).

## 공통 설명 (신청서 "반출 목적·처리 방법" 란)

- **반출 목적**: 2026 데이터안심구역 경진대회 기획서 작성. 공공배달앱 '대구로'에서 아동급식카드 결제가 발생하는 시간·계절 패턴을 일반 결제와 비교하고, 가맹점의 급식카드 등록 현황과 실제 결제 발생의 관계를 파악한다.
- **사용 데이터**: 대구로 결제 정보(INS_DAEGURO_PAY), 가맹점 정보(INS_DAEGURO_SHOP)
- **집계 기간**: 2023-06 ~ 2025-06 (결제수단 값 목록 파일만 전체 기간 2022-01 ~ 2025-06)
- **개인·사업장 식별정보**: 모든 파일에 가맹점코드·고객코드 등 가명 ID와 개별 거래 레코드가 **없다.** 전부 집계표다.
- **최소 집계 기준(억제)**: 급식카드 관련 칸은 건수 5 미만, 고유 가맹점 3 미만, 고유 고객 5 미만이면 값을 비웠다(빈칸). 관측 0인 칸도 같은 방식으로 비웠다(0과 소수를 구별할 수 없게). 가맹점 수 집계표는 3 미만을 비웠다.
- **추가 보호 조치**: 급식카드 시간대 표는 23시~05시를 한 칸으로 합쳤다. 비율 열은 넣지 않았다. 표의 분류 축은 최대 3개다. 한 그룹 안에 억제 칸이 하나만 있는 경우가 없음을 확인했다.

### 파일별 정의 보충

- **급식카드 결제**: 결제수단 = `아동급식카드`, 결제 상태 = `완료`. 동일 행 제거 안 함.
- **일반 결제**: 결제수단이 `아동급식카드`가 아닌 완료 결제.
- **학사 구분(R)**: 1·2·8월 = 방학, 7·12월 = 전환, 그 외 = 학기 (월 단위 근사).
- 파일 6·9의 일반 결제는 규모가 커서 관측 0인 칸을 0으로 표시했다(1~4건만 비움).
- 파일 1의 결제수단 값 이름은 결제 수단의 종류(예: 카드, 네이버페이)이며 개인·사업장 정보가 아니다.
