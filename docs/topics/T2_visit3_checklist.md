## 2. P0 판정 — 결과를 보기 전에 고정한 규칙(D-014). 번복하지 않는다

**ym이 빈칸인 줄은 승인시각이 없는 행이다.** "2023-05 이전"에 넣지 않는다(P1 둘째 표, P2, P3 모두 해당).

1. 급식 외 코드의 CHILD_DISC_AMT>0 (P1 첫 표): 가장 많은 코드 ___ ___건 (그 코드 n의 ___%) → □없음·드묾 □흔함
2. 2023-05 이전 CHILD_DISC_AMT>0 (P1 둘째 표): 값이 있는 달 ___ / 17개월(2022-01~2023-05), 주된 코드 ___
3. 방학월(22-01·02·08, 23-01·02)에 늘었는가: □예 □아니오
4. 행복페이 방학 비중(P2): 2022년 ___% (카드 ___%, 균등 25.0), 2023년 ___% (카드 ___%, 균등 28.6) → □두 해 모두 높다 □한 해만 높다(플랫폼 계절성) □높지 않다
5. 급식 결제에 표지가 있었는가(P1b): 2023-06~12 급식 결제 중 CHILD_DISC_AMT>0 비율 ___% → □있다 □거의 0이다(그 시기에는 표지가 기록되지 않았다)

**판정 순서**: 1이 "흔함"이거나 5가 "거의 0"이면 **C**다. 1은 확장 정의가 "CHILD_DISC_AMT>0 = 급식"을 전제하기 때문이고, 5는 표지가 없던 시기라 이전 기록을 판단할 수 없기 때문이다. 둘 다 아니면 2·3을 본다.

| □ **B** | 매월 반복되고 방학에 증가 | 주 분석은 25개월 유지, 확장판(2022-01~)은 기간 민감도로만 쓴다 |
| □ **C** | 의미 불명이거나 급식 외 코드에 흔함 | A로 처리하고 한계에 명시한다 |

## 4. 오류가 나면

- **보고 형식**: 셀 이름, 오류 마지막 줄, 셀의 몇 번째 줄에서 났는지
- `NameError`는 앞 셀을 돌리지 않았다는 뜻이다. 셀 의존 관계는 다음과 같다: P1b·P2←P1, M2·M3←M1, M4←M2, M5←M1·M3·M4, M6←M1·M2·M3, A2~A4←A1. **A1은 P1이 만든 `a`를 덮어쓴다.** 그래서 A1 뒤에 P1b·P2를 다시 돌리려면 P1부터 돌린다
- `KeyError '이름'`이 나면 S1 출력과 대조해 그 이름만 고친다
- M2·M3에서 `uniquely valued Index`가 나면 SHOP_ID가 중복됐다는 뜻이다. 보고한다
- 커널을 재시작했으면 S1을 돌린 뒤, 필요한 셀의 선행 셀만 다시 돌린다
