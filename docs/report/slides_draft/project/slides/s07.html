전처리는 다섯 단계. 급식 결제는 결제수단이 아동급식카드이고 결제가 완료된 건이며, 2023년 6월부터 25개월이다. 기간은 사전에 정한 규칙으로 3차 방문에서 확정했다. 레짐은 방학·전환·학기로 나눈다. 공간은 가맹점 법정동을 행정동과 이어 결합 단위 71곳으로 묶었다. 반출할 때는 작은 칸과 역산되는 칸을 가렸다.
