# 3차 방문 실행 결과 보고 양식

계획서·체크리스트의 현장 기록 항목을 모은 빈 양식이다. 실제 실행 결과를 아직 입력하지 않았다. 기대값을 실제값 자리에 옮겨 적지 않는다. 확인하지 못한 항목은 `미확인`, 실행하지 않은 셀은 `미실행`으로 적는다.

반출 승인 전 수치·표는 센터 내부 기록과 반출 신청 메모에 남긴다. 외부 노션·채팅에는 승인받은 자료와 내용만 옮긴다. 센터 내부 현장 기록은 `[잠정 — 반출 전]`, 승인 파일로 검수한 수치는 `[반출 승인 파일로 검수 완료]`로 구분한다.
