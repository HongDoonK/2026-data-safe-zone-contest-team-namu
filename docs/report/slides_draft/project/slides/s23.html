Ⅶ. 한계

한계를 먼저 밝히고, 대응을 붙인다

한계대응
결제 위치 ≠ 아이의 집일반 결제로 집 동네를 추정해 주문 흐름으로 보정 (4차)
아이가 아닌 성인의 소득30·40대(부모 세대) 저소득 비율로 대신하고 ‘간접’ 근거로 표시
앱 점검은 2026-10 화면‘단가가 1만 원으로 오른 지금도 남은 장벽’으로만 해석
계정 ≠ 아동효과는 ‘방학 한 달 이용 계정’ 단위로만 말한다
판단 불가 칸숨기지 않고 다음 방학 점검 항목으로 넘긴다
결과를 본 뒤 바꾼 규칙 2건바꾸기 전 판정도 함께 공개한다

23

한계를 먼저 밝힌다. 결제는 가게 위치라 집 위치가 아니고, 소득은 성인 자료이며, 앱 점검은 현재 화면이다. 각각 주문 흐름 보정, 부모 세대 소득, 현재 단가 기준 해석으로 대응한다. 판단 불가와 사후 개정은 숨기지 않는다.
