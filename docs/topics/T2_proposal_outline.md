> **"가게를 더 모으는 사업보다, 방학마다 같은 로그로 덜 쓰는 동을 다시 판정해 필요한 몇 곳에 해결방안 집중"** (2026-10-20, 4차 결과 기준 · 덱 2쪽)
>
> 10-15판 "급식카드 배달의 벽은 '가게가 있느냐'가 아니라 '1끼 한도 안에서 시킬 수 있느냐'다"는 4차 결과(방학 이용자 99.5%가 하루 1만 원 넘게 결제한 날이 있음 → 쓰는 아이는 1끼 값에 막히지 않음, 18쪽)와 맞지 않아 바꿨다. 아래 세 층 문장은 10-15판 기록이다.
