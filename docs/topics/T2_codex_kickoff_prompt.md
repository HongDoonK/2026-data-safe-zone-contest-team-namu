# Codex 킥오프 프롬프트 — T2 컨텍스트 인지용

> **용도**: Codex 세션을 새로 열 때 붙여넣는다. Codex는 `AGENTS.md`를 자동으로 읽지만, 이 프롬프트는 **실제로 읽고 이해했는지 검증하는 단계**를 강제한다.
> **작성**: 2026-09-14 (1차 반출 결과 반영). 프로젝트 상태가 바뀌면 §3 정답표도 함께 갱신한다.

## 1. 사용법

1. Codex에 저장소 폴더를 연다.
2. 아래 §2 블록을 **통째로** 붙여넣는다.
3. Codex가 이해 확인 답변 10개를 내면, **§3 정답표와 대조**한다. 틀린 항목이 있으면 해당 파일을 다시 읽으라고 지시한다.
4. 통과하면 §4의 첫 작업 템플릿 중 하나를 붙여넣는다.

## 4. 첫 작업 템플릿 — 이해 확인 통과 후 하나씩

### 4-A. 1차 반출물 정리·검증·시각화

```text
9_11_데이터분석결과물/ 의 t_month.csv, t_week_hour.csv로 다음을 만들어라.

1) 정리 스크립트: 수치를 정수형으로, 요일 '와'를 '화'로 교정하고 요일 순서(월~일) 고정.
   원본 파일은 수정하지 말고 교정본을 별도 경로(outputs/export_0911/)에 저장.
2) 검증: 두 표의 건수 합계 차이(억제분)를 계산해 출력. 결과 문서 §1의 값과 일치하는지 확인.
3) 그림 2장:
   - 월별 건수·손님수 시계열 (학기/방학/전환 구분 음영. 구분 기준은 결과 문서 §3.1 정의를 그대로)
   - 요일×시간 히트맵 (억제 셀은 회색 + "집계 기준 미달" 범례. 빈칸으로 두지 말 것)
4) 수치를 새로 만들거나 해석 문장을 쓰지 마라. 그림 제목·축에 "아동 수" 표현 금지(계정/결제로).
완료 후 생성 파일 목록과 검증 결과만 보고하라.
```

### 4-B. 억제 함수 구현

```text
설계서 §7.2와 AGENTS.md §4-4의 억제 규칙을 함수로 구현하라.

suppress(df, count_col, shop_col, cust_col, n_min=5, shop_min=3, cust_min=5,
         secondary=True) -> (df_suppressed, report)

- 1차 억제: 기준 미달 셀을 NaN으로
- 보완 억제: 행·열 합계로 1차 억제 셀이 역산되지 않도록 추가 셀 억제
- report: 1차·보완 억제 셀 수, 억제 전후 합계
- pytest 단위 테스트 포함 (경계값 4/5, 2/3 케이스, 보완 억제가 실제로 역산을 막는지)
- pandas + numpy만 사용
합성 테스트 데이터는 테스트 코드 안에서만 만들고 파일로 남기지 마라.
```

### 4-C. 게이트 스크립트 수정판 (안심구역 반입용)

```text
설계서 §4.1의 GATE-0 스크립트를 §1.10-B와 §1.10-F에 맞게 다시 작성하라.
이 코드는 팀원이 안심구역 PC(인터넷 차단)에 들고 가서 실행한다.

필수 반영:
1) 첫 단계에서 nrows=0으로 실제 헤더를 출력하고, 컬럼명은 config(JSON — 분석 PC에 PyYAML이 없을 수 있으므로 YAML 금지)로 받는다.
   한글·영문 두 매핑 예시를 config에 모두 넣어라.
2) '아동급식카드' 문자열을 하드코딩하지 마라. 지급구분의 전체 유니크 값과 건수를 먼저 덤프하고,
   값×연월 교차표를 2022-01부터 만든다. 급식 관련 값은 사람이 목록을 보고 config에 지정한다.
3) 지정된 값으로 N, N_SHOP(전 기간 고유), MONTHS, 최초·최종 월을 산출하고
   설계서 §4.2 분기 기준에 대입한 판정을 출력한다. 임계값은 설계서 값 그대로.
4) 실행 조건(필터 값, 파일 경로, 실행 시각, 코드 버전)을 결과와 함께 텍스트로 저장한다.
5) usecols + chunksize, dtype=str, strip, to_numeric(errors="coerce").
6) 공표·반출용 표는 4-B의 suppress()를 통과시킨다.
7) synthetic/ 에 스키마 형식만 맞춘 합성 CSV를 만들어 end-to-end 실행을 검증하라.
   합성 분포를 현실적으로 만들지 말고, 출력물에 SYNTHETIC 표시를 넣어라.
완료 후 실행 방법(현장에서 칠 명령어)과 생성 파일 목록을 보고하라.
```

## 5. 운영 메모

- **순서 권장**: 4-B(억제 함수) → 4-A(반출물 시각화, 억제 표시 재사용) → 4-C(게이트 수정판, suppress 재사용).
- **4-C가 다음 방문 전 최우선 산출물**이다. 결과 문서 §8의 1순위 반출 요청(필터 정의·값 목록)을 이 스크립트가 만든다.
- Codex 결과물은 Claude가 리뷰한다(CLAUDE.md Agent Roles). 특히 억제 로직과 게이트 판정 출력은 리뷰 없이 반출 신청에 쓰지 않는다.
- 프로젝트 상태가 바뀌면(2차 반출, 설계 변경 채택) **§2의 질문과 §3 정답표를 함께 갱신**한다. 낡은 정답표는 틀린 이해를 통과시킨다.
