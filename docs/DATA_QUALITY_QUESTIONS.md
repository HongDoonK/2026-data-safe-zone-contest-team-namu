# DATA_QUALITY_QUESTIONS.md — 실데이터 확보 후 초기 EDA 체크리스트

> 정의서만으로는 답할 수 없는 항목들이다. 실제 데이터를 확보하면 Codex가 이 문서를 초기 EDA 체크리스트로 사용한다.
> 일반 체크리스트(모든 데이터셋 공통) → 데이터셋별 핵심 확인사항(카탈로그에서 `[VERIFY_WITH_DATA]`로 표시된 항목 정리) 순으로 구성했다.

---

## 1. 공통 체크리스트 (모든 데이터셋에 적용)

데이터셋을 로드할 때마다 아래 항목을 표준적으로 확인한다.

### 1.1 규모/구조
- [ ] row 수, 컬럼 수
- [ ] 정의서 상 예상 파일 크기(MB/GB)와 실제 크기 일치 여부
- [ ] 정의서에 명시된 PK(복합키 포함)의 실제 유일성(uniqueness) — 중복 row 존재 여부
- [ ] wide-format 컬럼(예: 시간대별/요일별/연령대별 N개 컬럼)이 실제로 정의서대로 존재하는지, long-format으로 변형되어 있지는 않은지

### 1.2 기간/시계열
- [ ] 실제 관측 시작~종료 시점 (정의서의 "시작시점/마지막시점"과 비교)
- [ ] 기간 내 결측 구간(특정 월/일이 통째로 빠진 경우)
- [ ] 갱신주기(월/일/시)와 실제 관측 간격 일치 여부
- [ ] timestamp 정밀도(초 단위까지 정확한지, 자정으로 뭉개진 값은 없는지)

### 1.3 결측/이상치
- [ ] 컬럼별 결측률
- [ ] 수치형 컬럼의 이상치(음수 금액, 0으로 채워진 결측 등 — 특히 정의서에 "0으로 표기(결측 대체)"라고 명시된 컬럼 우선 확인)
- [ ] 범주형 컬럼의 실제 유니크값이 정의서에 명시된 코드값과 일치하는지(코드북 대조)

### 1.4 편향/분포
- [ ] 지역별(시도/시군구/읍면동) 관측 밀도 — 특정 지역 데이터 과소/과다 여부
- [ ] 기간별 관측 밀도 — 특정 시기 집중 여부
- [ ] class imbalance(라벨/카테고리형 타겟이 있는 경우 클래스 비율)
- [ ] 범주형 변수의 cardinality(고유값 개수) — 특히 코드성 컬럼(업종코드, 상품코드 등)

### 1.5 식별자/연결
- [ ] 가명화 ID(개인/사업장/가맹점 등)의 실제 유니크 개체 수
- [ ] 동일 데이터셋 내부 테이블 간 조인 성공률(카탈로그 "연결" 표시 항목)
- [ ] 조인 후 매칭되지 않는 row 비율과 그 원인

### 1.6 익명화/제약
- [ ] 어떤 수준까지 익명화·가명화·합성(synthetic)되었는지 데이터 제공 문서(설명자료) 재확인
- [ ] 소규모 셀(예: 특정 읍면동의 특정 연령대 소수 인원) suppression(마스킹) 여부 — k-익명성 적용 흔적
- [ ] 재식별 위험이 있는 조합(희귀 조합) 존재 여부

## 2. 데이터셋별 핵심 확인사항

### 건양대학교병원
- [ ] (1-1) 목록 시트(2020-2025) vs 소개 시트(2018-2023) 기간 불일치 — 실제 데이터가 어느 쪽인지
- [ ] (1-1) 6개 서브테이블(건강검진DB/자격DB/진료DB 4종)의 RN_INDI 기준 조인 성공률, 개인당 평균 진료기록 수
- [ ] (1-1) 문진 파생 컬럼(약 50개)의 결측률 — 설문 미응답 처리 방식
- [ ] (1-2, 1-3) 이미지 라벨 클래스 실제 비율(정의서 수치와 일치 여부), 이미지 해상도/포맷 통일성

### 경북대 첨단기술원
- [ ] (2-1 대구로) 목록 시트(2022-01~06) vs 소개 시트(2022-01~2025-06) 기간 불일치 해소
- [ ] (2-1 대구로) SHOP_ID/CUST_ID의 실제 유니크 개수(소개 시트에 건수는 있으나 유니크 개체 수는 없음)
- [ ] (2-2 상수도) virtl_no 기준 계량기-고지-민원-공사 조인 성공률, 세대별 주계량기(mnmrnr_virtl_no) 계층구조 검증
- [ ] (2-3 교통량) 40여 개 방향×차종 컬럼의 실제 결측/0값 비율(카메라 미작동 구간)
- [ ] (2-4 경상북도개발공사) "전국" 표기와 실제 데이터의 지리적 범위(특정 단지 한정 여부)
- [ ] (2-4) 코드북.xlsx의 실제 코드값(약정항목코드 등) 확보 및 매핑
- [ ] (2-5 KIAP) 설비 6종 간 DataTime 정합(초 단위 동기화 여부), 알람/고장 발생 빈도(클래스 불균형이 클 것으로 예상)

### 농림수산식품교육문화정보원
- [ ] (3-1) FCLT_ID 기준 환경/시설/생육/경영 4개 테이블 조인 성공률, 21개 농가 실제 분포
- [ ] (3-1) 환경 데이터의 측정 주기(일/시간) 및 결측 패턴(센서 장애 구간)
- [ ] (3-4) "등외등급/이상치 제외" 처리 전 원데이터 대비 표본 크기 손실률

### 전북특별자치도 국민연금공단
- [ ] (4) 0003/0004가 실제로 집계 테이블인지 개별 레코드인지 확정 — grain 확인이 이 데이터셋군의 최우선 과제
- [ ] (4) 소득구간·업종 등 저빈도 셀의 suppression(마스킹) 존재 여부
- [ ] (4) 3개월(2026-04~06)이라는 짧은 기간이 계절성 없는 안정적 스냅샷인지, 특이월인지

### 한국국토정보공사(LX)
- [ ] (5-1) 8.2GB 전국 필지 데이터의 실제 처리 방법(샘플링 필요 여부, 지역별 분할 처리)
- [ ] (5-1) PNU-법정동코드-공시지가 등 병합 출처 테이블 간 결측(예: 공시지가 없는 필지 비율)
- [ ] (5-2) 수치지형도 shp가 별표 2의 전체 레이어를 포함하는지, 일부만 포함하는지
- [ ] (5-3) DEM 5m 래스터의 좌표계/해상도 실측 확인

### 한국데이터산업진흥원(K-DATA) 계열
- [ ] (6a BC카드) "합성데이터"의 통계적 특성(원 데이터 대비 노이즈/편향), 소규모 시군구×업종 조합의 신뢰도
- [ ] (6b KCB) 22개 소득구간 카운트의 합계가 전체 인구/가입자 수와 일치하는지(sanity check)
- [ ] (6c SKT) UTM-K 좌표 → 행정동 매핑표(서울_GB_테이블정의서.xlsx) 확보 및 격자-행정동 대응 정확도
- [ ] (6d 나이스지니데이타) 5개구/10개 상권이라는 좁은 범위의 대표성, 상권 데이터의 "현금거래 추정" 로직 상세
- [ ] (6e 신한카드) SHC002의 11차원 집계에서 저빈도 셀(예: 특정 시간대×성별×연령×소득구간 조합)의 신뢰도/마스킹 여부, 3.13GB 규모 처리 전략
- [ ] (6f 도로교통공단) 90여개 컬럼의 실제 결측 패턴(특히 안전벨트/에어백 등 세부 항목), 가해자/피해자 연령대 "1의자리 반올림/삭제" 처리로 인한 정밀도 손실
- [ ] (6g LH) HO_ADM_NO 기준 계약-관리비 조인 성공률, 925MB 관리비 데이터의 실제 row 규모
- [ ] (6h KECO) 27개 데이터셋 간 BPLC_ID/PRFMNC_ID 일관성, 클러스터 C(고형연료)의 시설코드 표준화 여부, 클러스터 A(폐기물 5종시설) 간 동일 시군구·기간 비교 가능성

### 한국도로공사
- [ ] (7-1) 34년 장기 데이터의 컬럼 정의 변경 이력(연도별 스키마 변화 가능성 — 특히 오래된 연도일수록 결측 많을 것으로 예상)
- [ ] (7-1) 피해금액이 "백만원 단위 반올림"된 값이라는 점이 소액 사고 분석에 미치는 영향

- [ ] (7-4 KOTI) Level5.5 링크ID가 표준 도로망 코드와 매핑 가능한지

### 한국전력공사(KEPCO)
- [ ] (8) "시간대별 사용량" 컬럼이 실제로 wide(0~23시 24컬럼)인지 long(시간대 컬럼 1개+값 컬럼)인지 구조 확인 — 정의서만으로는 판단 불가
- [ ] (8) 001(전체 이용자)과 002(충전사업자)의 중복 포함 관계(002가 001의 부분집합인지, 별개 집계인지)

### 한국지능정보사회진흥원(NIA) 계열

## Status

- Phase 1에서는 이 체크리스트를 채울 수 없다(실제 데이터 없음). 실제 데이터 확보 직후 Codex가 데이터셋별로 이 문서의 해당 섹션을 EDA 결과로 채워 넣는 것을 권장한다(예: `## 건양대학교병원` 아래에 실측 결과 bullet 추가).
- 체크리스트 완료 결과는 이 문서에 직접 갱신하거나, 분량이 커지면 `docs/eda/` 하위에 데이터셋별 리포트로 분리하고 이 문서에서 링크한다.
