## 검증 기록

코드 선작성 전 기본 계약 29개를 실행해 구현 부재로 전부 실패함을 확인했다. 구현 후 29개 통과. selfcheck·합성 생성기 테스트 3개도 먼저 실패를 확인한 뒤 구현해 32개 통과했다. 테스트의 고유 수 열 접근은 pandas 메서드와 이름이 겹쳐 `.nunique`에서 `["nunique"]`로 바로잡았다(기대값 1은 변경하지 않음).

**단계 0 인수 검증 1바퀴:** 추가 적대적 입력과 보완 억제 인수 테스트를 포함해 42개 통과, 1개 실패. selfcheck 통과. 영문·한글 SYNTHETIC 각 48행을 chunksize=3으로 읽어 16청크·고유 고객 12·시각 오류 2행을 확인. 6개 범위 경계값 모두 손계산 일치. Python 3.8 AST 파싱 11파일 통과, pandas/numpy 외 외부 import 없음. 보완 억제 픽스처의 write_export는 unresolved로 거부(반출 CSV 0개).

실패 원인은 확인 요청 1의 고정 상한과 보완 억제 대상 값의 불일치다. 코드의 조용한 통과·범위 임의 확장·기대값 완화로 고치지 않았다. 성공 인수 기준을 `unresolved 없음`으로 해석한 테스트는 실패 상태로 유지한다. **이 해석 대신 이 입력의 반출 거부를 정상 완료로 인정할지도 확인이 필요하다.**

**최종 동일 입력 재확인(구현 수정 없음):** `pytest tests/visit2 -q`: 42 passed, 1 failed, 4.87s, exit 1. selfcheck exit 0. `SYNTHETIC_verify_stage0.py`는 소형 입력·환경 점검 통과 후 동일 관문 FAIL, exit 1. 재확인은 2번째 수정 시도가 아니며, "수정 없이 통과"한 바퀴는 없다.

사용자의 단계 0 실패 시 전체 중단 규칙을 적용했다. 단계 0은 미완, 단계 1~7은 미착수다. 계산 방식이나 기대값 확인이 필요한 상황에서 동일 실패를 6회 반복하지 않았다. 전체 보고는 `docs/visit2_implementation_report.md`를 본다.
