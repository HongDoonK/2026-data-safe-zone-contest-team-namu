# T2 3차 방문 할 일

데이터안심구역 3차 방문(2026-09-29 ~ 10-02) · 쉬운 말 정리

> 괄호 안 이름(S1, P1, M4 …)은 인쇄용 체크리스트의 셀 이름이다.
> 반출 승인 전까지 현장 숫자는 모두 **잠정**으로 적는다.

---

## 들어가기 전

- [ ] 센터에 **동 이름을 결과물에 넣어 가지고 나와도 되는지** 묻는다. 안 된다고 하면 바로 공유한다(동 이름 대신 번호를 붙이는 코드가 계획서에 없다).
- [x] 대구시 급식카드 단가 확인: **2023~2025년 8,000원**일 가능성이 높다(평화뉴스 2023-10-17, 동구청 안내 2025-08-18). 2026년은 **10,000원**·하루 최대 **30,000원**이다. 데이터 기간 중 단가가 바뀌지 않았으므로 단가별 분석(A4)은 하지 않는다.
- [x] 대구로 급식 서비스는 **2023-06-01**에 시작했다. 배달팁은 2023년에 전액, 2024년부터 최대 4,000원 지원했다 → '아동 할인 금액' 칸은 **배달팁 지원액**일 가능성이 크다.
- [x] 사용 가능 시간 확인: **06:00 ~ 23:00**, 그날 쓰지 않은 금액은 사라진다 → 2차 결과의 "급식 결제만 23시에 끊긴다"와 맞는다.
- [ ] 두 규정의 출처(링크·공고명·날짜)를 기록한다. 기획서 인용에 필요하다. 대구시 아동급식 지원 조례(2022-12-12 제정, 개정 없음)에는 숫자가 없다 → 연도별 "아동급식 계획"이나 대구시 안내문에서 찾는다(담당: 대구시 교육청소년과).
- [ ] (가능하면) 이용시간 규정(06:00 ~ 23:00)의 출처와, 2023 ~ 2025년에도 같았는지 찾는다.
- [ ] 계획서의 코드 부분(§2~§5)과 체크리스트를 인쇄한다.
- [ ] 퇴실 시각을 확인하고, **그 90분 전을 분석 종료 시각**으로 정한다(기본 14시).
- [ ] 출발 전 결정: ① 일반 결제의 작은 칸도 숨길지(A3) ② 방학·학기·전환기별로 숨긴 칸 수를 어떻게 셀지(M4) ③ 기간 판정 해석 두 가지(B와 C가 겹칠 때 어느 쪽인지, "매달"은 몇 달인지)

## 안에서 할 일 — 순서를 바꾸지 않는다

### 0. 준비 (S1, 10분)

- [ ] 파일 경로를 넣고, 컬럼 이름이 계획서와 같은지 확인한다.

### 1. 분석 기간 정하기 (P1~P3, 30분)

확인할 것: 2023년 6월 이전에도 급식카드 결제가 '행복페이'나 '카드' 같은 다른 이름으로 기록돼 있었는가.

- [ ] '아동 할인 금액' 칸이 0보다 큰 결제가 2023년 5월 이전에도 있는지, 있다면 어느 결제수단에 있는지 본다.
- [ ] 급식 결제에서 '아동 할인 금액'이 있는 건수를 달마다 본다(P1b, 1줄 · P1 바로 뒤). 2023년 6월부터 이 칸이 기록됐는지, 갑자기 0이 되는 달(배달팁 지원 중단)이 있는지 확인한다.
- [ ] 행복페이 결제가 해마다 방학(1·2·8월)에 유독 많았는지 본다.
- [ ] (애매할 때만) 급식카드를 쓴 계정이 그 전에 어떤 결제수단을 썼는지 참고로 본다.
- [ ] 판정을 적는다. **한 번 정하면 바꾸지 않는다.**

판정 기준

- **A** — 이전 기록이 없거나 드문드문
- **B** — 매달 있고 방학에 늘어남 (늘린 기간은 참고용으로만 쓴다)
- **C** — 판단이 안 됨 (2023년 급식 결제에 '아동 할인 금액'이 거의 없으면 여기에 해당)
- 어느 쪽이든 본 분석은 **25개월(2023-06 ~ 2025-06)**이다.

### 2. 동네별로 보기 (M1~M6, 90분)

- [ ] 가맹점을 동별로 묶고, 동마다 급식 결제와 일반 결제를 센다.
- [ ] 동 × 방학·학기·전환기 표를 만든다. 결제가 너무 적은 칸은 숨긴다.
- [ ] 동별 요약표를 만든다: 가게 수, 급식카드 등록 비율, 급식 결제 비중이 대구 평균보다 높은지 낮은지.
- [ ] **급식카드 등록도 했고 장사도 하는데 급식 결제가 한 번도 없는 가게 1,412곳** 가운데, 지금도 영업 중이고 대구로를 탈퇴하지 않은 곳이 몇 곳인지 센다. → 기획서 "먼저 확인할 가게" 목록의 대상

### 3. 결제 금액 보기 (A1~A4, 60분)

- [ ] 금액 칸끼리의 관계를 확인한다. 예: "총액 = 카드 승인액 + 아동 할인 금액"이 맞는가 → 아동 할인 금액 칸의 뜻을 알아낸다. 배달팁 지원액이라면 이 관계가 맞고, 금액이 4,000원 근처에 몰린다.
- [ ] 아동 할인 금액이 보통 얼마인지 다시 확인한다(2차 때 잘못 적힌 것으로 보이는 값이 있었다).
- [ ] 결제 금액을 500원 단위로 나눠 급식과 일반을 비교한다. 가장 많이 몰리는 금액대가 같은지 다른지만 본다.
- 단가별 분석(A4)은 하지 않는다. 데이터 기간 중 단가가 바뀌지 않은 것으로 보인다.

### 4. 하지 않는 것

- 시간이 남아도 결제-주문-배달 연결 분석은 하지 않는다. 준비된 코드가 없다 → 반출 신청을 일찍 시작한다.

## 분석 종료 시각이 되면 — 무조건 반출 신청

> 심사가 3일 걸린다. 신청을 못 하면 그날 한 일이 전부 없어진다.

- [ ] 하던 셀을 멈추고 신청서를 쓴다.
- [ ] 가지고 나올 것 확인: 표 파일 4개 + 설명 메모 1개
- [ ] 합계 줄이 없는지 본다.
- [ ] 숨긴 칸이 한 묶음에 딱 하나만 있지 않은지 본다(합계에서 빼서 숨긴 값을 되살릴 수 있으면 안 된다).
- [ ] 동 이름 허가 여부와 파일 내용이 맞는지 본다.
- [ ] 메모에 적는다: 기간 판정과 그 이유, 급식 결제 정의, 숨김 규칙
- [ ] 메모에 표 파일에 안 들어가는 숫자도 적는다: 지금도 영업 중인 가게 수, 금액 칸 관계 결과. 작은 숫자는 "5 미만"으로 쓴다.
- [ ] 메모도 같이 반출되는지 담당자에게 확인한다(2차 때는 빠졌다).

## 현장 규칙

- 코드는 손으로 치고, 셀마다 확인 숫자가 체크리스트와 맞는지 본다.
- 반출 승인 전 숫자는 모두 "잠정"으로 적는다.
- 오류가 나면 셀 이름, 오류 메시지 마지막 줄, 몇 번째 줄에서 났는지를 전달한다 → 다시 칠 줄만 받아서 고친다.
