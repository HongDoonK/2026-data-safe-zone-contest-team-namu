# SYNTHETIC 테스트 입력

`SYNTHETIC_secondary_group.csv`는 V2-00 §3.6과 §5의 충돌을 손계산으로 재현하는 두 행이다.
합계가 10일 때 1차 억제 후 한 칸의 값이 확정되고, 공개된 다른 칸까지 숨기면
명세의 두 칸 범위 [0,4] 합은 최대 8이라 합계와 양립하지 않는다.

이는 실데이터나 실제 분포를 바탕으로 만든 입력이 아니다.
`SYNTHETIC_verify_stage0.py`는 이 거부 결과와 소형 영문·한글 청크 읽기를 재현하고
`SYNTHETIC_stage0_evidence.json`에 기록한다. 2026-09-18 사용자 승인으로 이 반출 거부를 정상 처리로 인정하며, 검증 성공 시 종료 코드는 0이다.

테스트 실행 시 생기는 `SYNTHETIC_<uuid>/`는 이 폴더 안에만 만들고 Git에서 제외한다.
인수 테스트는 xfail 처리하지 않는다. 사용자 승인된 정상 거부를 직접 검사한다.
