> 주제 선정·순위는 이미 결정되었으며 이 문서에서 다시 논의하지 않는다. 이 문서의 목적은 **실데이터 확보 전에 확정할 수 있는 모든 것을 확정**하고, 확정할 수 없는 것은 **방문 1일차 검증 절차와 분기 기준**으로 바꿔놓는 것이다.

### 2.1 분석 단위와 두 층위

> **개인정보·재식별 원칙(설계에 내장)**: L1 결과는 안심구역 내부에서만 존재하고 **반출 대상은 L2 집계뿐**이다. 추가로 **최소 셀 규칙**을 적용한다 — 어떤 L2 단위든 유효 주거용 계량기 수 `n < 30`이면 지도·순위표에서 마스킹하고 상위 단위로 병합한다. 이 규칙 자체를 기획서에 명시하면 "현실 적용 가능성"(실현가능성 20점) 근거가 된다.

### 2.2 패널 정규화 — 모든 특징량의 전제

정의서상 고지는 **월 단위가 아니라 검침 주기 단위**이며 격월고지가 섞여 있다 `[CONFIRMED]`. 따라서 원시 `usgqty`를 그대로 월 시계열로 쓰면 안 된다.

**단계 N1. 일평균 사용량으로 변환**

```
span_days_it = date(thsmon_mtinsp_day) - date(lsmth_mtinsp_day)      # 검침 기간 일수
daily_it     = usgqty_it / span_days_it                              # ㎥/일
```

**단계 N2. 검침 구간을 달력 월로 균등 배분(uniform allocation)**

각 고지 행이 덮는 `[lsmth_mtinsp_day, thsmon_mtinsp_day)` 구간을 달력 월에 겹치는 일수 비율로 나눠 배분한다.

```
m_i,y = Σ_t  daily_it × (구간 t 와 월 y 의 겹치는 일수)
```

이 방식이 격월고지·검침일 변동·기간 불일치를 **동시에 흡수**한다. 이후 모든 특징량은 `m_i,y`(월별 배분 사용량 ㎥/월)와 `daily_it` 위에서 계산한다.

**단계 N3. 파생 플래그**

| 파생 변수 | 정의 | 용도 |
|---|---|---|

### 2.3 "주거용 계량기" 판별 규칙

`wrpp_induty`·`calbr`·`mrnr_se`·`mnmrnr_yn`의 **실제 값 집합은 코드파일이 없어 미지다** `[CONFIRMED — 코드파일 미제공]`. 따라서 규칙은 **후보 형태로 고정하고, 검증 절차로 확정**한다.

#### 후보 규칙 R (기본안)

```
주거용_개별계량기 =
    mrnr_no   == 'A00'                                  # 원계량기만 (§1.5 ③)
AND mnmrnr_yn  == 'N'                                   # 세대별 주계량기(공용) 제외
AND mrnr_se   IN {원계량기, 빌라형 세대별계량기}          # 상가형 세대별계량기 제외
AND wrpp_induty ∈ RESIDENTIAL_SET                       # ★ 1일차에 값 사전 확정
AND wrpp_addinduty IS NULL or ∉ COMMERCIAL_SET          # 겸업(주상복합 점포) 배제
AND calbr <= 25                                         # 보조 조건, 아래 R-b 참조
```

각 조건의 근거와 위험:

| 조건 | 근거 | 위험 / 대안 |
|---|---|---|
| `mrnr_no='A00'` | 정의서: A00 원계량기, CXX 보조계량기 `[CONFIRMED]` | 위험 낮음 |
| `mnmrnr_yn='N'` | 주계량기는 **공용 사용량**을 포함하므로 가구 궤적이 아님 `[CONFIRMED 정의]` | 주계량기는 **별도 층위**로 분석(다세대 건물 단위 궤적) |
| `mrnr_se` 필터 | 정의서에 3분류가 명시 `[CONFIRMED]` | 실제 값 표기(공백·괄호)가 정의서 문구와 다를 수 있음 `[VERIFY_WITH_DATA]` |
| `wrpp_induty` 필터 | 상수도 요금 업종 체계에 가정용 계열이 존재 `[INFERRED]` | **가장 큰 미지수.** 값 사전 확정이 G2 게이트 |
| `calbr <= 25` | 가정용 급수관 구경은 통상 13/15/20mm대 `[INFERRED]` | **단독 기준으로 쓰지 않는다.** 업종 필터의 **교차 검증용**으로만 사용 |

#### 대안 규칙

- **R-a (보수적, 업종 단독)**: `wrpp_induty ∈ RESIDENTIAL_SET`만 적용. 구경 조건 제외.
- **R-b (엄격, 업종 ∩ 구경)**: R-a + `calbr <= 20`.
- **R-c (포괄, 업종 ∪ 소구경)**: 업종이 미상·결측이어도 `calbr <= 20 AND mrnr_se = 원계량기`면 포함.

**세 규칙을 모두 계산하고, 최종 결과를 R-a 기준으로 보고하되 R-b·R-c로 민감도 분석을 붙인다.** 유형화 결과(유형 개수·유형별 비중·핫스팟 순위)가 세 규칙에서 안정적이면, "계량기는 가구가 아니다"라는 §1의 최대 반박에 대한 **정량적 방어**가 된다. 이것은 기획서의 논리성 30점에 직접 기여한다.

#### 판별 규칙의 검증 방법 (실데이터 확보 후)

| V# | 검증 | 통과 기준(제안) | 실패 시 |
|---|---|---|---|
| V1 | `wrpp_induty` × `calbr` 교차표 | 가정용 계열이 소구경에 집중 | 업종 라벨 재해석, 사무국·기관 담당자 문의 |
| V2 | `wrpp_induty` × `mrnr_se` 교차표 | 빌라형 세대별계량기가 가정용에 집중 | R-c로 전환 |
| V3 | 규칙별 **월 사용량 중앙값** 분포 | 주거용 후보군의 분포가 상업용 후보군보다 낮고 좁음 | 규칙 재설계 |
| V4 | **외부 검증** — 대구 읍면동별 주민등록 세대수(공개 통계)와 리·법정동별 주거용 계량기 수의 상관 | 상관계수가 높고 회귀 기울기가 1 근방 | 규칙이 주거를 못 잡고 있음 → R-c 전환 후 재검증 |
| V5 | 규칙 간 **유형 배정 일치도**(ARI) | 세 규칙에서 유형 구조가 유사 | 민감도 한계를 기획서에 명시 |

> **V4가 이 설계의 핵심 방어선이다.** 외부 공개 통계(주민등록 세대수)와의 대조는 안심구역 밖에서 미리 준비할 수 있고(§4 W0), "계량기 ≠ 가구" 반박에 대해 **수치로 답하는 유일한 방법**이다.

### 2.5 블록(L2) 지표 — 여기서 깊이가 나온다

"군집화 + 지도"로 끝나면 감점된다는 [TOPIC_EVALUATION.md](../TOPIC_EVALUATION.md) §1의 지적에 대한 답이 이 절이다. **L2에서 세 가지 정량 분석을 추가한다.**

#### (가) 감소의 분해 — shift-share

블록 `b`의 총 사용량 변화를 세 성분으로 분해한다.

```
ΔW_b = W_b,T − W_b,0
     = [ Δn_b × ū_b,0 ]        ← 외연 효과 (계량기 수 변화 = 세대·점포 이탈)
     + [ n̄_b × Δū_b ]          ← 내연 효과 (계량기당 사용량 변화 = 가구 축소·절약)
     + [ Δn_b × Δū_b ]         ← 상호작용
```

업종별(주거/비주거)로 나눠 반복하면 **"이 블록은 비어서 줄었나, 남은 사람이 덜 써서 줄었나"**에 답한다. 이 질문은 정책적으로 전혀 다른 처방(도시재생 vs 복지)으로 이어지므로, **하나의 분해 그림이 T1의 실용성 주장을 지탱한다.** 공개 통계로는 절대 불가능한 분해이며(총량만 공개), **미개방데이터 활용 기여도(본선 30점)의 직접 증거**가 된다.

#### (나) 시차 교차상관 — 궤적이 인프라 사건보다 앞서는가

`리 × 월` 패널을 만든다.
- 좌변: `n_emergency_b,t` (DGWT_005 긴급복구 건수), `n_civil_b,t` (DGWT_003 민원 건수)
- 우변: `vac_index_b,t` (해당 월 시점의 공동화 지표), `Δ주거용 계량기 수`

```
음이항 고정효과 패널:
  E[n_emergency_b,t] = exp( α_b + γ_t + Σ_{k=0..6} β_k · vac_index_b,t−k )
```

`β_k`의 부호·유의성 패턴이 **선행/동행/후행**을 구분한다. 블록 고정효과 `α_b`가 "원래 노후한 동네"라는 교란을, 시간 고정효과 `γ_t`가 전시적 추세를 흡수한다. **인과 주장은 하지 않고 "시간적 선후 관계"로만 표현한다** (D-004에서 확립된 프로젝트 원칙과 동일한 절제).

#### (다) 공간 자기상관 — 무작위가 아님을 증명

- 공간가중행렬 `W`: LX_001 필지를 리·법정동으로 dissolve해 얻은 폴리곤의 **queen contiguity** (§3.3)
- 전역 Moran's I (999회 순열검정) → "공동화는 흩어져 있지 않다"
- 국지 Moran (LISA) → High-High(공동화 핫스팟) / Low-Low / 공간이상치 4분류
- FDR(Benjamini–Hochberg) 다중검정 보정 — 리 단위 수백 개를 동시 검정하므로 **필수**

### 2.6 가설 ↔ 산출물 1:1 매핑

| 가설 | 답하는 표/그림 | 검정·통계량 | 비고 |

| **H1** 주거용 계량기 궤적은 소수의 해석 가능한 유형으로 분리된다 | **[그림 1]** 유형별 대표 궤적(중앙값 + IQR 밴드)<br>**[표 1]** k별 실루엣·CH·BIC·Gap<br>**[그림 2]** 유형별 F 특징 프로파일(레이더) | 실루엣 계수, GMM BIC, Gap statistic, 부트스트랩 ARI | k는 데이터가 결정 `[VERIFY_WITH_DATA]` |
| **H1b** 유형 구조는 주거용 판별 규칙에 강건하다 | **[표 2]** R-a/R-b/R-c 간 유형 비중·ARI | Adjusted Rand Index | §2.3 반박 방어 |
| **H2** 유형 분포는 공간적으로 군집한다 | **[그림 3]** LISA 핫스팟 지도(리 단위)<br>**[표 3]** 전역 Moran's I | Moran's I + 999 순열, LISA + FDR 보정 | LX GEOM 기반 W |
| **H3** 정수처분·폐전은 특정 유형에 과대표집된다 | **[그림 4]** 유형 × `meter_sttus` 히트맵(표준화잔차)<br>**[표 4]** 교차표 + 행/열 비율 | χ² 독립성 검정, 표준화잔차, Cramér's V | **기술적 비교이며 예측이 아님**을 캡션에 명시 |
| **H4** 감면 수급은 저사용 지속 시에도 정수처분과 덜 연결된다 | **[표 5]** 유형 × 감면수급 × 정수처분율 3원 층화표<br>**[표 6]** 로지스틱 회귀 계수 | `logit(정수처분) ~ 유형 + 감면 + 유형×감면 + calbr + induty + gu FE` | **인과 아님.** "제도의 보호 효과"가 아니라 **"조건부 연관"**으로 서술. 역인과(정수처분 대상이 애초에 감면 미신청) 가능성을 본문에 명시 |
| **H5** 공동화 블록은 긴급복구 빈발 구역과 겹친다 | **[그림 5]** 공동화지수 × 긴급복구밀도 중첩 지도<br>**[그림 6]** 시차 β_k 계수 플롯 | 음이항 고정효과 패널 (§2.5 나), 이변량 Moran's I | 인과 아님, 선후 관계만 |
| **H6** 블록 사용량 감소의 외연/내연 성분 비중은 지역마다 다르다 | **[그림 7]** 리별 shift-share 분해 막대<br>**[그림 8]** 외연효과 × 내연효과 사분면 산점도 | 분해 항의 기여율(%), 사분면 분류 | **T1의 차별화 핵심** (§2.5 가) |
| **H7** 공동화는 건조환경(지가·건물·필지 구조)과 연관된다 | **[표 7]** 리 단위 공간회귀 계수표 | OLS → Moran's I of residuals → SLM/SEM (Lagrange Multiplier 검정으로 모형 선택) | LX 결합 (§3.4). 시점 불일치를 한계로 명시 |
| **H8** 공동화·취약은 소득 분포와 어떻게 겹치는가 | **[그림 9]** 4분면 지도(공동화 × 저소득 비중) | 상관·분위 교차표 | KCB 결합, 행정동↔법정동 변환 오차 명시 (§3.5) |

> **가설과 무관한 분석은 하지 않는다.** 위 9개 그림·7개 표가 기획서 30p의 분석 파트 골격이며, §6의 산출물 스펙과 1:1로 연결된다.

### 3.2 LX 결합 — 어떤 키로 붙이는가

**문제**: 상수도는 주소가 **좌표가 아니라 `city`/`gu`/`dong`/`li` 텍스트**다 `[CONFIRMED]`. LX는 코드와 명칭과 지오메트리를 모두 가진다 `[CONFIRMED]`.

#### 대안 1 — 명칭 정규화 직접 조인 (Baseline)

```
KEY_water = normalize(gu) ‖ normalize(dong) ‖ normalize(li or '')
KEY_lx    = normalize(SGG_NM) ‖ normalize(EMD_NM) ‖ normalize(RI_NM or '')
```

`normalize()`: 공백·중점·괄호 제거, 유니코드 NFC 정규화, 구 명칭 별칭 사전 적용(행정구역 개편 이력).

- **장점**: 외부 데이터 없이 즉시 실행 가능. 1일차에 매칭률을 바로 볼 수 있다.
- **위험**: 표기 흔들림(`달성군 화원읍` vs `화원읍`), 동명이동(대구 내 동일 동명), 개편 이력.
- **검증**: `unmatched_rate`, 그리고 **역방향 검증** — LX 대구 법정동 목록에는 있으나 상수도에 없는 동(급수 미보급 지역인지, 매칭 실패인지 구분).

#### 대안 2 — 법정동코드 경유 조인 (**권장**)

행정안전부 **법정동코드 전체자료**(공개, 요강 §5 허용)를 준비해 명칭 → 10자리 법정동코드를 부여한 뒤, LX의 `EMD_CD`(8자리 = 법정동코드 앞 8자리)·`RI_CD`(10자리)와 **코드로** 조인한다.

```
water_addr(시도,시군구,읍면동,리)
   → [법정동코드 사전]  → bjd_cd(10)
   → LX: RI_CD == bjd_cd            (리가 있는 경우)
         EMD_CD == bjd_cd[:8]       (리가 없는 경우)
```

- **장점**: 표기 흔들림을 코드 표준이 흡수. **폐지·변경 법정동의 이력 코드까지 사전에 포함**되어 있어 2020~2024 데이터와 2026 LX 스냅샷의 시점 차이를 다룰 수 있다.
- **비용**: 사전 준비 필요 — **안심구역 밖에서 W0에 미리 만든다**(§4). 반입 가능 여부는 `[ASK]`.
- **이중 검증**: 대안 1과 대안 2의 결과를 대조해 불일치 건을 수동 확인한다. 이 대조표 자체가 기획서 부록의 "데이터 전처리 타당성" 증빙이 된다.

#### 대안 3 — Dasymetric 재배분 (해상도 향상, 선택)

리·법정동 단위가 너무 거칠 때, 해당 블록의 계량기 수를 **LX 필지 속성으로 가중해 필지·격자에 재배분**한다.

```
가중치 w_p ∝ 1{BLDRGST_PK is not null} × f(JIMOK)     # 건물이 있고 지목이 '대'인 필지에 집중
계량기수_p = 계량기수_블록 × w_p / Σ_{p∈블록} w_p
→ 250m 격자로 재집계 → 격자 단위 히트맵
```

- **장점**: 지도 표현력이 크게 개선된다(본선 표현력 10점). 리 단위 색칠보다 훨씬 설득력 있는 시각화.
- **한계**: **개별 계량기의 실제 위치가 아니라 통계적 재배분**이다. 지도 캡션과 방법론 장에 반드시 명시하고, **정책 판단 단위는 어디까지나 리·법정동**임을 못 박는다. 이 절제를 명시하는 것 자체가 신뢰도 점수가 된다.

#### 대안 4 — 커버리지 정규화 (분모 문제 해결)

계량기 수를 그대로 비교하면 큰 블록이 항상 크게 보인다. LX로 **분모**를 만든다.

```
주거가능필지수_b = COUNT(필지 WHERE JIMOK ∈ 대지계열 AND BLDRGST_PK IS NOT NULL)
계량기밀도_b     = 주거용계량기수_b / 주거가능필지수_b
공동화율_b       = 장기0유형 계량기수_b / 주거용계량기수_b
```

`계량기밀도`가 비정상적으로 낮은 블록은 **매칭 누락 의심 구역**으로 자동 플래그되어, 대안 1·2의 품질 점검에도 쓰인다.

> **채택**: 대안 2를 주 경로, 대안 1을 교차검증, 대안 4를 정규화에 상시 사용, 대안 3은 시각화 단계에서 선택 적용.

### 3.3 LX 8.2GB 처리 전략


```python
# 2) 파이썬 경로 (ogr2ogr 불가 시) — pyogrio는 where 절을 드라이버 레벨에서 처리
import geopandas as gpd
gdf = gpd.read_file("LX국토정보필지_전국.shp", engine="pyogrio",
                    where="SIDO_CD = '27'")

# 3) 리/법정동 폴리곤 생성 (공간가중행렬·지도 밑그림)
gdf["BJD"] = gdf["RI_CD"].where(gdf["RI_CD"].notna() & (gdf["RI_CD"] != ""),
                                gdf["EMD_CD"])
poly = gdf.dissolve(by="BJD", aggfunc={"PAREA": "sum", "JIGA_ILP": "median"})

# 4) 블록 건조환경 지표
attr = (gdf.assign(has_bld=gdf["BLDRGST_PK"].notna(),
                   is_dae=gdf["JIMOK"].isin(DAE_SET),
                   is_public=gdf["OWNER_CD"].isin(PUBLIC_OWNER_SET))
           .groupby("BJD")
           .agg(n_parcel=("PNU", "size"),
                bld_ratio=("has_bld", "mean"),
                dae_ratio=("is_dae", "mean"),
                public_ratio=("is_public", "mean"),
                jiga_med=("JIGA_ILP", "median"),
                parea_med=("PAREA", "median"),

```

`[VERIFY_WITH_DATA]` `DAE_SET`(대지 계열 지목)·`PUBLIC_OWNER_SET`(국·공유 소유코드)의 실제 값은 데이터에서 확인 후 확정.
`[ASK]` 안심구역 분석 환경에 `geopandas`/`pyogrio`/GDAL이 설치돼 있는지 — **없으면 전체 공간분석 경로가 막힌다.** 사무국 사전 문의 항목(§7 Q3).

### 3.5 LH·KCB 결합 규칙

**LH KLH_001(계약, 대구분)**
- 키: 법정동코드 → §3.2 대안 2와 동일 경로
- 파생: `공공임대_호수_b`, `공급유형 구성비`(영구임대/국민임대/행복주택), `준공년월 중앙값`
- 가설: 영구·국민임대 밀집 블록은 **저사용이면서 정수처분은 낮은** 패턴을 보이는가(감면·복지 개입이 이미 작동하는 구역) `[VERIFY_WITH_DATA]`
- 한계: LH 계약은 **호 단위**지만 위치는 시군구·법정동 수준 `[CONFIRMED — DATA_CATALOG 6g]`. 블록 단위 집계만 가능.

**KCB004(소득)**
- **행정동 ↔ 법정동 다대다 문제**. 처리 규칙:
  1. 원칙: **법정동을 기준 격자로 삼고**, 겹치는 행정동의 소득 분포를 **면적 가중 또는 주거가능필지 수 가중**으로 배분한다(LX가 가중치를 제공한다 — 여기서도 LX가 접착제 역할)
  2. 다대일(여러 법정동 → 한 행정동)인 경우: 해당 행정동 값을 그대로 부여하고 **`kcb_precision = 'coarse'` 플래그**를 단다
  3. 결과 보고 시 **`coarse` 블록은 별도 표시**하고, 민감도 분석으로 `coarse` 제외 결과를 병기한다
- 파생: `저소득비중_b` = (C1+C2+C3)/Σ, `고령저소득비중_b` = AGE_CD∈{60,70}의 C1~C3 비중, `소득지니_근사`

### 3.6 기획서에서 연계를 "증명"하는 방법

### 6.1 최종 산출물 3종

#### 산출물 A — 「수도궤적 진단지수」 (2축 지수)

블록(법정동, 달성·군위는 리) 단위로 **두 개의 독립된 지수**를 만든다. 하나로 합치지 않는 것이 핵심 — 정책 처방이 다르기 때문이다.

| 지수 | 구성 요소 | 단위 | 해석 |
|---|---|---|---|
| **VAC-W (수도궤적 공동화지수)** | 장기0·급감후저사용 유형 비중, `zero_run_tail` 보유 계량기 비율, 주거용 계량기 수 순변화율, 계량기밀도(LX 정규화) | 0~100 정규화 | "이 블록은 비어가고 있는가" |
| **VUL-W (수도궤적 생활취약지수)** | 정수처분·급수중지 비율, 감면 수급 계량기 비율, 저사용 지속 유형 비중, 요금민원 밀도 | 0~100 정규화 | "이 블록에는 끊기기 직전의 사용자가 많은가" |

- **가중치 결정**: 임의 가중을 피하고 **① 동일가중 ② PCA 제1주성분 ③ Entropy weight** 세 방식을 계산해 **순위 상관(Spearman)이 안정적임을 보인 뒤 동일가중을 기본**으로 채택한다. 가중치 임의성은 지수형 공모전 작품이 가장 자주 공격받는 지점이므로, 이 민감도 분석을 본문에 배치한다.
- **표기 원칙**: 지수는 **"측정된 값"이 아니라 "관측된 사용 궤적의 요약"**이다. 기획서에서 "위기가구 수"로 읽히지 않도록 단위와 캡션을 관리한다.

#### 산출물 B — 「대구 수도궤적 지도」 (4종)

| 지도 | 단위 | 표현 | 대응 가설 |
|---|---|---|---|
| **B1. 4분면 진단 지도** | 법정동/리 | VAC-W × VUL-W 를 **이변량 색상(bivariate choropleth 3×3)** 으로 표현 | 종합 |
| **B2. LISA 핫스팟 지도** | 법정동/리 | High-High / Low-Low / 공간이상치 4색 + 유의성(FDR) 음영 | H2 |
