## 7. 2025년 수상작 분석 — 무엇이 실제로 이기는가 `[CONFIRMED — 사이트 히스토리]`

2025년 총 28개 수상팀의 주제·활용 데이터를 확인했다.

### 7.1 상훈 구조가 기관별 쿼터를 뒷받침한다
대상 2(과기정통부·국토교통부장관상) + 최우수 8 + 우수 7 + 데이터미래인재특별상 11로 구성되며, **거의 모든 참여·후원기관 명의로 상이 하나씩 배분**되어 있다(도로공사장상, LX사장상, 농정원장상, NIA원장상, 한전사장상, K-DATA원장상, 경북대첨단기술원장상, 전북도지사상, KCB사장상, 신한카드사장상, 나이스지니데이타사장상 등). §4의 쿼터 조항과 정합한다.

**단, 상훈 명의 기관과 실제 활용 데이터 기관이 일치하지 않는 사례가 다수다.**
- 경북대첨단기술원장상 수상팀 → K-DATA "지역별 매출 및 이용고객 정보"만 활용
- 신한카드사장상 수상팀 → 한국도로공사 "고속도로 교통사고 데이터"만 활용
- 나이스지니데이타사장상 수상팀 → K-DATA 상권 데이터 활용
→ 쿼터 기준이 데이터 제공기관이 아닐 가능성을 시사한다. §4 `[ASK]` 1번이 그래서 중요하다.

### 7.2 수상작의 공통 형태
- **2~3개 기관 데이터 결합이 다수.** 대상 2팀 모두 결합형(LX + K-DATA / LX + K-DATA + 한전).
- **산출물이 "지수 / 지도 / 최적 입지 / 시뮬레이션 / 솔루션"** 형태. 순수 학술적 인과추론·계량경제 분석 형태의 수상작은 확인되지 않는다.
